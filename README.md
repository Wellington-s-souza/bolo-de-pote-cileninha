# 🍰 Bolo de Pote da Cileninha

Landing page para venda de bolos de pote artesanais, feita para direcionar clientes diretamente para o WhatsApp e fechar o pedido.

## 🔗 Demo

> Depois de publicar (GitHub Pages, Netlify, Vercel etc.), troque este link pela URL final:
> `https://seu-usuario.github.io/bolo-de-pote-cileninha/`

## ✨ Funcionalidades

- Header fixo (sticky) com logo, menu de navegação e botão de WhatsApp
- Menu responsivo (hambúrguer) para telas pequenas
- Animação de entrada das seções ao rolar a página (scroll AOS)
- Botões de call-to-action com link direto para o WhatsApp, com mensagem pré-preenchida
- Layout responsivo (desktop, tablet e celular)
- Espaço reservado no hero e na seção de sabores para receber fotos reais dos produtos

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, Flexbox, Grid)
- JavaScript puro (sem frameworks)
